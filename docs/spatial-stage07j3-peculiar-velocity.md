# Stage 07j.3 — Nominal radial peculiar velocity

The Appearance colour mode Vpec uses the symmetric, zero-centred numeric scale. A separate Off / Selected / All radial-arrow layer preserves the current colour encoding (including population comparison). Arrows are off by default. Both modes require individual galaxies; entering group mode disables arrows and resets Vpec colour to morphology. H0 is shared with the selected-object environment HUD. H0, arrow scope, scale and absolute speed threshold are session-local, validated and resettable. No change to adopted catalogue values. The residual is V_LG - H0 D, with the existing independently eligible catalogue distance subset (REVIEW_READY, NOT_REVIEWED or VERIFIED, subject to current volume and distance mode). Domain is before spatial/population cuts; visible arrows are intersected with rendered PGCs. Missing inputs remain unavailable, zero residual remains a valid colour but has no arrow. Duplicate identities fail closed. Negative/positive shafts point toward/away from the observer along the displayed radial direction. The same signed residual is used in every coordinate frame. Length in Mpc display units is proportional to absolute residual at the declared Mpc/100 km/s conversion; no physical displacement, trajectory, transverse motion or reconstructed velocity field. Catalogue LG-frame velocities are paired with observer-centred catalogue distances/directions as an explicitly approximate convention, not a transformation to barycentric positions. No propagation of velocity/distance uncertainties or significance claims pending verified paired error evidence and frame QA. The numerical length reference is in the legend; clean PNG exports include the arrows but not UI/legend, so annotate H0 and scale separately. GPU buffers are owned by the existing renderer and refreshed without camera recreation. Requires full project QA and real-catalogue/browser acceptance. No backend, database or production changes.
