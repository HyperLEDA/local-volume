# Stage 07h.2a: Task-oriented spatial workspace

View, Appearance, Select and Compare are mutually exclusive control pages, not separate scenes. Hidden tool pages stay mounted; changing pages does not change renderer dependencies or session preferences. Selection and comparison state remain visible in a compact status strip. The Appearance reset stays global. Search browsing starts closed; explicit search or Browse opens it. Region and population tools share one transfer action. Comparison counts appear in the right colour legend. Distance interval quality stays visible when intervals are on; essential marker symbols stay visible; reference guides and size details remain accessible in a disclosure. Physical-parameter warnings stay visible alongside the active colour legend. On small screens the header and canvas precede the tool pages. Scientific filters, source data, render engine, backend, and session schema are unchanged. Browser acceptance required.
