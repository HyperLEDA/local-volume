# Stage 06a — catalogue-based group scene (#43, #46, #44)

The interactive catalogue map and the independently reviewed scientific geometry have different eligibility rules. Stage 05c/05d evidence is preserved: `distance_3d_eligible` continues to mean the strict evidence gate and is not silently changed. `buildGroupScene` is a frontend-only adapter for existing group detail data. It does not write data, recompute distances, modify the group definition, or replace the Aladin view. It works with Stage 05c, whether or not the optional Stage 05d evidence was installed.

The scene uses the unique explicit root member and its finite positive adopted D and valid ICRS position as the origin. Its origin and review status travel with the scene. If a root has no usable distance or sky direction (or is the Milky Way), the scene returns CENTRE_UNAVAILABLE; it does not choose another member or assign a fiducial distance. Duplicate/mismatched membership IDs and missing/ambiguous roots return INVALID_MEMBERSHIP. All entries remain available for inspection, including unconfirmed candidates. No new group relationships are inferred.

Axes are east, north, positive outward line-of-sight, in kpc; all coordinates are relative to the adopted centre, not to an estimated barycentre. For direction n_i and adopted D_i, use 1000 * projection of (D_i n_i - D_c n_c) in the centre basis. Category semantics:

- INDIVIDUAL_ADOPTED: existing individual-distance classification, irrespective of independent review; actual catalogue position, not a proof of the distance or gravitational binding.
- MODEL_ESTIMATE / UNCLASSIFIED_ESTIMATE: same coordinate transform using the adopted value, distinctly styled and excluded from independent-depth estimators. No heuristic reinterpretation of BTF or other HOLD classifications.
- ASSIGNED_PROJECTION: schematic common-distance orthographic projection, (1000 D_c n_i·east, 1000 D_c n_i·north, 0). D_i is retained as metadata, not used to represent depth. Rear-hemisphere members remain direction-only instead of folding into the near plane. This is not a ray-plane intersection or a physical location.
- DIRECTION_ONLY: no display position; keep ICRS direction and centre-basis direction where possible. No fictitious sphere, centre point, or arbitrary distance. Milky Way PGC 5064336 is deliberately excluded from extragalactic positions.
- UNAVAILABLE: no valid direction. Member remains in the list.

The displayPositionKpc field is for rendering only. `strictGeometryEligible` additionally requires accepted membership, DIRECT_MEASURED, both existing API verification flags, value VERIFIED and the same gate for the centre. No depth statistic, mass, or pair measurement is computed from the display position. Unconfirmed members are kept with acceptedMember=false and never receive an interval or strict eligibility. A future viewer must visibly distinguish every category and candidate status.

Distance intervals are endpoints along the member's observer ray at D_i - e_minus and D_i + e_plus, in the same fixed-centre frame. A verified interval needs VERIFIED and its evidence flag, with accepted individual membership and consistent source lineage. A traceable but NOT_REVIEWED individual interval may be displayed as CATALOGUE_UNREVIEWED (not a verified uncertainty). HOLD, STALE, BLOCKED, UNAVAILABLE, missing review, untraceable or invalid intervals are omitted; the adopted central value remains. The centre's own uncertainty is not jointly propagated into other members' intervals; no Gaussian or joint confidence interpretation is implied. The camera extent is the largest finite position norm, not a halo or physical group radius, and excludes error bar lengths. A later renderer may choose framing padding; no coordinates are rescaled in the data model.

Future viewer: lazy WebGL module, preserve the 2D default, orbit/pan/zoom and orthographic presets, morphology and absolute B magnitude (no apparent-magnitude substitution), distinct marker types and legend, selection inspection and real hierarchy; maintain separate nonphysical directions. This commit only provides the testable scene model and its contract, not the UI or a new public API.

## Offline pilot QA

The accompanying CSV is derived by running this model on the 76 PGCs in the previously supplied production NGC 5128 membership snapshot joined to the user's Stage 05c read-only audit CSV, revision 7. This is a reconstructed fixture, not a live API request. The optional Stage 05d audit is also tested; neither changes the catalogue positions. The tests compare the independent exact spherical separation formula and the existing geometry implementation, including RA wrap, poles, wide angular separations, absent centre, invalid membership, and uncertainty semantics. Full Bun/lint/build and live API integration must be checked in the user's worktree.
