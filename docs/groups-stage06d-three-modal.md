# Stage 06d — modal Three.js group explorer

Supersedes the inline SVG renderer from Stage 06bc. The group sky map remains mounted; the 3D Group button opens a lazy-loaded native modal dialog. Close by × or Escape. Scene state is discarded on close, so relations and the selected-distance interval start hidden on every new opening. No DB, API, source-distance, or strict geometry gate changes.

The renderer uses Three.js 0.180.0 and matching @types/three, with OrbitControls, an orthographic camera, equal physical scale on all axes, and a screen-calibrated scale bar. Grid is the schematic XY reference plane at the centre; marker size encodes absolute B magnitude (not physical diameter); colors reuse the morphology palette. Group-assigned objects remain explicitly schematic, and model/unknown positions have distinct shapes. Relations use the existing exact-pair tidal code; dashed edges involve schematic endpoints. The selected distance interval is drawn along the individual observer ray only if Stage 06a permits it; unreviewed intervals are dashed. The inspector always exposes every member, including objects without coordinates. No pair distance or dynamical binding is inferred from these visual positions.

Dependencies must be installed on the local worktree; `--qa` updates the Bun lockfile deliberately and then checks frozen install, formatting, lint, tests and build. Installer compares the old Stage 06bc files modulo Prettier, makes backups, and refuses unrelated modifications. No browser/WebGL acceptance is implied by static tests. Check modal appearance, all camera presets, scrolling, mobile layout, object navigation, repeated open/close, edge visibility and WebGL fallback in a real browser. The previous camera helper/test stays for marker sizing compatibility; no SVG scene remains wired into the page.
