# MW.5 visual acceptance follow-up

Remove the two inline paragraphs on the MW group page; the scientific scope
remains in the existing documentation, figure metadata, and property help.
The interactive and hierarchy-preview sky maps use the standard directed MD
edges and sign colours. All-sky lines are split with the existing Atlas
projection-discontinuity helper and rebuilt on pan, zoom and resize. The
interactive hit layer is enabled; MW subgroup contours remain disabled until
validated on the full sky. Portraits remain unannotated as for other groups.

In the global Atlas real-space Galaxies mode, the nominal MW centre supplied
by the already-qualified MW envelope is a separate MD-layer reference only.
Only visible, unique, traceable individual satellite/galaxy endpoints with
matching formula/revision are connected, using explicit catalogue MD ids.
No new positions in the extragalactic sample, no change to membership,
physical calculations, density, FoF, MST, paired redshift or verified-only
mode. No database update is needed. The line endpoints do not imply boundness.
