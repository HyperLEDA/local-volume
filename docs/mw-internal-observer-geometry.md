# MW.4a: internal observer geometry

The MW.3 refresh is unchanged. The catalogue centre of PGC 5064336 is
adopted from its source direction and distance. Group 3D coordinates use
1000 (D_i u_i - D_MW u_MW), rotated into the existing orthonormal
centre-based east/north/LOS basis. This is a translation of observer-based
vectors, not an external small-angle projection. Rear-hemisphere members
are not dropped. The centre may be nominal but the existing strict review
gate is unchanged. Group-assigned satellites remain direction-only: no
artificial plane at the centre distance. The global Atlas has a separate
[MW group envelope](mw-atlas-group-envelope.md); MW remains excluded from
the ordinary extragalactic sample.

For the MW root, external-host R_p, related diagnostic figures, orbital
mass, crossing time and common-LOS velocity summary are suppressed. The
native observer-distance/velocity diagram and luminosity function remain.
The MW.2 backend already suppresses the external projected extent.

Group sky maps use the same 360-degree AIT mode as the global sky Atlas.
The portrait remains SIN. Automatic SIN fitting is bypassed for MW.
Directed MD links use projection-aware splitting and redraw on pan/zoom;
see [MD links](mw-md-links.md). All-sky subgroup contours remain disabled.
Full-sky cached preview generation has not been independently validated.
Galactocentric diagnostics and global Atlas representation have passed
numerical acceptance on the isolated test clone. No source data changes.
