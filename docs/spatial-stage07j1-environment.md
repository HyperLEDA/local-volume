# Spatial environment pilot (07j.1)

Nominal catalogue pilot, not an approved density estimator or a physical membership claim. Related #105, #67, #108. The environment uses the input Atlas sample, its volume and distance quality, before region/population filtering, regardless of group aggregation. It excludes assigned/model distances, HOLD/non-independent lineage and stale/blocked values. REVIEW_READY unreviewed values are exploratory; verified mode uses the existing strict gate. The root of a selected group is treated as one galaxy, not all its members.

Euclidean separation, closed sphere, self excluded, unique PGCs, nearest sorted by separation then PGC. Raw observed density N/(4 pi R^3/3) is not a completeness correction; 11 Mpc edge crossings flagged, angular masks, flux limits, distance errors and other selection effects uncorrected. H0=70 km/s/Mpc is an editable illustrative default, not an adopted cosmology. V_LG-H0 D is a nominal line-of-sight residual relative to that convention, not a peculiar velocity vector. No uncertainty implied. No writes to catalogue.
