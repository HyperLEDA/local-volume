# Stage 07e.4a — shared 3D navigation

Click or Tab to focus the canvas. Physical WASD codes and arrow keys pan continuously in screen coordinates at the current scale; Shift triples the speed. Enter focuses the selected visible object. Empty primary clicks clear selection, not camera. Drag threshold and multi-pointer cancellation prevent clearing on ordinary orbit/pinch gestures. Group Explorer gains double-tap focus with the Atlas 620 ms easing and a modest 2.5x target zoom (never zooms out); manual input interrupts flight. Header brand remains a link without hover underline. No scientific or database changes.

Browser QA: both renderers, both projections where available, physical keys on Cyrillic layout, repeated keys, input fields, Tab/blur, drag out and back, pinch, overlapping glyphs, Enter on hidden objects, repeated focus, reduced motion, header in both themes.
