# Stage 07i.1 — Atlas PNG export (07h.2a baseline)

Adds one Export PNG action to Appearance. No workspace changes from 07h.2b are included. The capture synchronously renders the existing scene at up to 3× CSS sampling (scene buffer capped at 4096 px per side and device limits), copies it into an independent canvas, restores the pixel ratio and redraws the live scene. The scene aspect, camera, selection and geometry are unchanged. Axes and an orthographic scale bar are drawn explicitly. Perspective images have no constant physical scale. The PNG contains the scene only, without an appended legend or criteria footer. The on-screen legend remains available. Document colour and selection conventions separately when using the image in a publication. PNG only; no vector claim. Full source/revision manifest and group image export remain separate work. Browser checks: compare screenshot framing, change theme and projection, export numeric and A/B colour modes, verify PNG dimensions and no live camera jump, try context failure.
