# Stage 07h.1 — Catalogue populations

Galaxy mode only. Any = union; All = intersection. No checked criteria means unrestricted. The B-band dwarf proxy is M_B >= -17 mag (inclusive); negative computed Theta1 is a nominal isolation proxy and not membership. Physical roots and members (including roots) use the complete validated snapshot; outside groups means covered, but not a member. T < 0, T = 0 and T > 0 are catalogue bins; missing values never match a criterion. Membership-dependent results fail closed until the snapshot is available; export is disabled. Counts use the current geometric, distance and volume selection before population filters. Groups are never classified by root photometry. Geometry and population filters combine by AND. Camera/colour domains remain based on the pre-population selection. Population-only and combined samples record the exact PGCs and population policy, not catalogue revision. Reset clears filters.
