# Stage 07g.1 — nominal Cartesian slicing

The slice is a closed slab in its declared observer-centred frame, in Mpc. The full thickness is specified. Only individual adopted catalogue positions can enter; verified mode further restricts the input. It is not a probability or a claim of a complete sample. Unknown, assigned, model, and unclassified depths are excluded. Switching coordinate frame preserves the physical slab. A new Apply uses the currently displayed frame. Group mode clears the slab. Guides are boundary circles intersected with the unsliced scene radius, not physical structures. Intervals are not clipped at nominal slice bounds; both MD endpoints must be in the selected sample. Camera extent/key refer to the unsliced scene, and colour scales still refer to the parent Atlas sample. Search, picking and counts use the selected PGC subset; the parent sky/table filter is unchanged. Session and Reset include the slice. Apply is explicit to avoid recreating the WebGL scene on every keystroke. Further spatial samples/export belong to #107/#78.
