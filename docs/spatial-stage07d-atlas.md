# Stage 07d — Global Spatial Atlas prototype (#87)

This is a local, read-only prototype, not scientific or release acceptance. It consumes the current Atlas selection and the Stage 07b source-paired evidence contract, without additional requests or database mutations. The pre-existing Aladin view remains mounted. The native dialog closes back to Sky. The ordinary Atlas selection, exports, query and group viewer are unchanged.

- Observer-centred, unscaled coordinates in Mpc: SGX/SGY/SGZ default; Galactic and ICRS available. No arbitrary radius cut at 11 Mpc. The observer host (PGC 5064336) is not an extragalactic marker. The origin symbol is an observer reference, not a catalogue galaxy.
- Default individual catalogue distances can include unreviewed values; strict verified-only mode follows the existing evidence gate. Group-assigned/model/unclassified estimates are visible only in the explicitly schematic all-catalogue mode. No positions for missing or invalid D, invalid directions, mismatched/duplicate PGC, or missing spatial contract. Never use legacy `dist` as fallback. All current sample entries remain in the inspector.
- Orthographic default, optional perspective (no uniform scale bar in perspective), canonical views, explicit Focus and Home, neutral equal-size symbols with optional existing morphology palette. Overlapping hits are a chooser. No physical measurements, invented groups or halos. The modal inherits the current theme at opening and permits a scene theme toggle.
- Batched `THREE.Points` per display class, existing shared glyph textures, camera, projection and demand-driven scheduler. No persistent render loop. Cleanup on close, fallback on context failure, manual retry. Actual performance and WebGL compatibility are not inferred from unit tests.
- The mode opens over the unchanged Sky view. Changes of frame, projection or depth mode re-fit the camera; reopening resets prototype controls. Full camera/selection persistence, advanced quantitative color/size, slices, interval overlays, group links, exports and linked state remain later work; do not treat this prototype as completion of #87.

## Local acceptance checklist
1. Run installer --qa. Confirm previous Group Explorer remains unchanged in browser. Open Spatial 3D on real catalogue and record displayed/valid/verified/missing counts; inspect one direct, assigned, model and missing distance. Compare with Group Explorer evidence for same PGC.
2. Switch three coordinate systems and canonical views. Verify handedness, isotropic orthographic scale, observer origin and no synthetic positions. Validate transforms independently (Astropy). Confirm perspective scale notice.
3. Pick an overlapping set, inspect each candidate, Focus and Home. Verify list selection does not move camera, galaxy link preserves existing Atlas selection navigation, Sky centre and FoV survive opening/closing. Apply Sky filters, reopen and compare counts. Check empty/verified-only state.
4. Check desktop/mobile portrait/landscape, light/dark, keyboard controls and context-loss fallback. Measure real-scene first load, FPS and repeated mount/unmount memory. Screenshots and GPU measurements are still required.
